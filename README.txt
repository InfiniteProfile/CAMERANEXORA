CAMERANEXORA: a fictional, endlessly generated camera universe. No photographs, no external data.
Run: open index.html directly, or serve with python3 -m http.server.
Every profile is computed from its numeric ID string (any length). Feed IDs run upward from 100000000000000000, so the feed never ends.
Typing any digit string in search shows the exact profile for that ID first. All cameras and brands are made up; each profile says so.
Images are SVG drawn by script.js (art function). Add camera shapes there; add worlds in the W array.
